Ejemplo de codigo

Como se crea un componente

Primero se crea una instancia con un objeto de opciones. Luego se llama a uno de sus metodos publicos. 

const modal = new Componentes.Modal({
    title: 'Aviso',
    content: 'Mensaje de ejemplo'
});

modal.open();
